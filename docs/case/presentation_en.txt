--- SLIDE 5 ---
WHAT "AGENTIC" MEANS
Give agents a clear role. Avoid decorative complexity.
1. Mobilize
Public data, tools, templates, or search engines.
2. Coordinate
Tasks, controls, intermediate decisions and interactions.
3. Adapt
Analysis according to context, preferences and constraints.
4. Explain
Sources, assumptions, factors, uncertainties and limitations.
We do not want to impose a particular architecture:
You can have an agent.
You can have more than one.
You can have specialized agents.
The important thing is not their number.
The important thing is to be able to answer this question:
Why does this agent exist and what value does it bring?
An agent could search and select data.
Another could analyze different scenarios.
Another could check certain constraints.
An agent or mechanism dedicated to explainability, etc.
Tip: Each component should have a clear role.

--- SLIDE 11 ---
THE RESPONSIBLE FRAMEWORK
A credible innovation also knows how to say what it does not know.
SIMULATION ONLY
No real transactions.
No personalized financial advice.
No confidential banking data.
Trust is earned through transparency.
✓
Distinguish between facts, assumptions and fictitious scenarios:  If a piece of information is a hypothesis, say so.
✓
Present important uncertainties:  If an outcome has significant uncertainty, show it.
✓
Provide concise and verifiable explanations:  If a piece of data does not allow a solid conclusion to be drawn, your solution must be able to communicate it.
✓
Staying true to observable sources and actions
✓
Don't invent a justification after the fact
A credible AI solution is not one that always claims to know the answer.
It is a solution that also knows how to explain when the answer is uncertain.
